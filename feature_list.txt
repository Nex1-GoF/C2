MainView 
- 4Panel 로 구성하기
- 교전할당 버튼
	교전할당 로직(가장 빠른 ID부터 하자..)
- 발사후 재발사까지 5초(발사대기시간)구현
- 발사 버튼
	발사과정 구현(progress_bar or text)

Target Panel
- 표적카드구현
	표적 ID,이미지 등등
- 표적 카드 레이어에 적재 구현 
	삽입, 삭제
- 표적 카드 선택 기능 구현 (유도탄하고 같이)
	전역으로 selected_표적id 같은거 넣기 

Map Panel
- 지도 구현
	캐시?기능 써서 오프라인에서 사용가능하게
- 지도위에 표적표시
	표적 위치에 마커 생성
	표적 위치+정보표시
	표적 이동방향 표시
	표적 이동시 갱신(임의데이터 만들어서 갱신)
	선택중인 표적 경로출력
- 표적or유도탄 선택기능
	ㄴ유도탄이나 표적을 선택하면 해당표적에 대응되는 유도탄도 같이 select해주기

- 시스템 메시지 출력
	출력후 Log에 넣기

	삭제?or 뒤로 미룰지
