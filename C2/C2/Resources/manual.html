C2 사용자 매뉴얼 (요약본)

1. 표적 교전 할당

  • 표적 카드에는 교전 할당 버튼이 있다.
  • 이 버튼을 누르면 시스템이 가장 적합한 미사일을 자동으로 선택하여 해당 표적에 연결한다.
  • 교전 할당이 완료되면 미사일 패널에서 할당된 표적 정보가 표시된다.

2. 미사일 발사

  • 교전 할당이 끝난 뒤 발사 버튼을 누르면 미사일 발사 절차가 시작된다.
  • 전원 점검 → BIT → 항법 정렬 → 키 전달 → 점화 준비 등 필요한 단계가 순서대로 자동 진행된다.
  • 절차 중 상태 변화는 미사일 카드에서 실시간 진행률과 상태로 확인할 수 있다.

3. 교전 상황 확인

  • 미사일이 발사되면, 지도 상에서 미사일과 표적의 궤적이 실시간으로 표시된다.
  • 표적 카드 또는 미사일 카드 중 하나를 클릭하면

    해당 교전 상황의 자세한 정보(거리, 상대 위치, 상태, PIP 위치 등)를 확인할 수 있다.

  • 필요하면 교전 중에도 다른 표적/미사일을 선택하여 정보를 전환해 볼 수 있다.

4. 기타 기능

  • 로그 패널: 시스템에서 발생하는 주요 메시지를 시간순으로 표시
  • 지도 확대/축소: 휠 조작 또는 버튼으로 확대·축소 가능
