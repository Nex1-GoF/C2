C2 사용자 매뉴얼

1. 표적 교전 할당

  • 표적 카드에는 교전 할당 버튼이 있다.
  • 이 버튼을 누르면 시스템이 가장 적합한 미사일을 자동 선택하여 연결한다.
  • 교전 할당이 완료되면 미사일 패널에서 할당된 표적 정보가 표시된다.

2. 미사일 발사

  • 교전 할당 후 발사 버튼을 누르면 미사일 발사 절차가 시작된다.
  • 전원 점검 → BIT → 항법 정렬 → 키 전달 → 점화 준비 등의 자동 절차가 진행된다.
  • 상태 변화는 미사일 카드에서 진행률·상태로 확인 가능하다.

3. 교전 상황 확인

  • 발사 후 지도에서 미사일과 표적의 궤적이 실시간 표시된다.
  • 표적 카드 또는 미사일 카드 클릭 시
    거리·상대 위치·상태·PIP 위치 등 자세한 교전 정보를 확인할 수 있다.
  • 다른 표적/미사일 선택으로 교전 정보를 즉시 전환 가능하다.

4. 기타 기능

  • 로그 패널: 시스템의 주요 메시지 표시
  • 지도 확대/축소: 휠 또는 버튼 사용
